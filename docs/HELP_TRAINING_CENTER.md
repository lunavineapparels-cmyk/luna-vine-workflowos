# Help & Training Center v0.4.0

Route: `/help`

The initial Help Center provides step-by-step guides for Getting Started, Control Tower, Evidence Vault, Release Gate, Marketing Psychology, Users/Roles/Entitlements, and Security & Access.

Long-term design: GitHub Markdown/MDX is the documentation source of truth; WorkflowOS renders approved versions and records training progress/acknowledgement in D1. The current migration seeds the first runtime articles so the feature can be tested immediately.

Definition of Done from v0.4 onward: **Build → Test → Secure → Document → Train → Deploy → Monitor**.
