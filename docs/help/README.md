# Luna Vine WorkflowOS Help & Training Center

Documentation source-of-truth convention for v0.4.0 onward.

Every production module must document: Purpose, When to use, Accountable role, Inputs, Step-by-step procedure, Example, Required evidence, Approval rules, Common mistakes, Troubleshooting, Security/privacy notes, and Completion criteria.

Initial runtime help articles are seeded by `migrations/0006_help_center.sql`. The long-term target is automated Markdown/MDX publishing into the Help Center so documentation remains code-reviewed and versioned.
